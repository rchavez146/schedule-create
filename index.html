Quick Guide

Schedule Maker Tutorial

Recommended workflow

Use a branch template as the safe starting point, then save weekly schedules as separate files. This keeps the app useful without needing a login or server.

Template First Weekly Files Secure Backup Print Ready
First Time

Initial Branch Setup

  1. Start with Branch Rules. This is where the branch builds the reusable setup before making weekly schedules.
  2. Set branch open/close times, open days, full-time shift times, part-time shift times, rotation weeks, employees, Station Plan, and Auto Fill Options.
  3. Use Create Branch Template after setup. This is the reusable file that saves branch rules, employees, rotations, shift times, task exemptions, station setup, and auto-fill options.
  4. Save that template JSON in a secure place, such as OneDrive or another approved branch folder.
Every Week

Returning User Plan

  1. Click Open File, import the branch template, then set week start and week type.
  2. Use Auto Fill Schedule, then adjust PTO, holidays, helper rows, notes, tasks, and Station Plan details.
  3. Click Save Weekly File to save the finished weekly schedule as its own JSON file.
  4. Print the Schedule tab and, if used, print the Station Plan tab separately.
Start

Top Buttons

  • Branch Rules is the starting point for branch templates.
  • Save Weekly File saves the finished week as a JSON backup.
  • Open File imports a saved JSON schedule or branch template.
  • Print prints the active tab only.
  • Auto Fill Schedule rebuilds target hours and fills the task tags enabled in Auto Fill Options.
Setup

Employees

  • Add name, key/drawer details, roles, fixed day off, target hours, Saturday rotation, and the auto-fill time list.
  • Use Lead Eligible and Do Not Auto Assign to control task and station auto-fill behavior.
  • Edit or remove employees from the roster card. The schedule updates after saving changes.
Rotation

Saturday Rotation

  • Choose the branch cycle length first in Branch Rules > Rotation Weeks.
  • Use Pair Rotation for two people alternating Saturdays.
  • Use Cycle Rotation for groups, especially odd-numbered teams.
  • Custom week type leaves Saturday open so a manager can build a special week manually.
Cells

Editing Cells

  • Click a schedule cell to open the side editor.
  • Set shift time, PTO, OFF, Holiday, Dark Cell, notes, colors, and tasks from the editor.
  • Use Add Custom Shift Time for unusual shifts, and save it if the branch uses it often.
  • Dark Cell blacks out a cell and counts zero hours. Holiday counts as 8 paid hours but does not count as staffed coverage.
Bulk

Multi-Cell Editing

  • Ctrl/Cmd + click cells to select multiple cells.
  • Bulk mode applies only the fields you change.
  • Use it for shifts, PTO, notes, colors, tasks, or station/lunch details.
  • Use Reset in the editor to clear selected cells, or Close to leave the selection.
Branch Option

Station Plan

  • Turn on Enable station, lunch, and lobby plan only if the branch uses station, office, lunch, or lobby lead planning.
  • Set stations/offices and lunch times in Branch Rules > Station Plan.
  • Use Save & Auto Fill Station Plan to assign configured locations to scheduled employees.
  • Station, lunch, and lobby lead details appear in the schedule cells and remain editable from the Station Plan tab.
  • Use the manager/supervisor exclusion if those roles should not be assigned stations or offices.
Helpers

Helper Rows

  • Click Add Helper Row when outside help is coming from another branch or talent pool.
  • Put the helper’s name in the note for the day they are helping, then add their shift.
  • Use Dark Cell on unused days if you want those helper cells blacked out.
Coverage

Auto Fill Coverage

  • Auto Fill rebuilds shifts to target hours first, then assigns enabled task tags using the branch open/close times.
  • Use More > Auto Fill Options to turn off task tags the branch does not want auto-filled or flagged, such as Night Drop.
  • Opener needs one other opener. Closer needs at least three coworkers closing too.
  • Use the Daily Coverage cards to check the enabled coverage requirements.
Files

Saving, Templates, And Print

  • Save Weekly File is the main backup for a completed weekly schedule. Keep the JSON somewhere safe so the schedule can be reopened later.
  • Create Branch Template saves clean setup rules for future weeks.
  • Templates do not include weekly notes, PTO, helper rows, or one-week task assignments.
  • Print prints only the active tab, which keeps the Schedule and Station Plan from mixing together.
Safety

Shortcuts And Resets

  • Cmd/Ctrl + S saves the current schedule file.
  • Cmd/Ctrl + Z undoes the last change.
  • Cmd/Ctrl + Shift + Z or Ctrl + Y redoes the change.
  • Reset Schedule rebuilds the week and removes helper rows.
  • Clear To Blank starts over from an empty canvas.
